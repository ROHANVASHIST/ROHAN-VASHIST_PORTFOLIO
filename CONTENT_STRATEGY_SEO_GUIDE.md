## 3. BLOG CONTENT STRATEGY

### 3.1 Article Structure

Each article should follow this structure for SEO and readability:

```
ARTICLE TEMPLATE:

📋 Meta Information:
- Title (50-60 characters): "How [Action] Works: [Benefit]"
- Slug: lowercase-with-hyphens
- Meta Description (150-160 chars): Summary with CTA
- Featured Image: 1200x630px (for social sharing)
- Reading Time: Auto-calculated
- Category: One primary, up to 3 tags
- Author: Rohan Vashist
- Publish Date: YYYY-MM-DD

📝 Content Structure:
1. Hook (Opening paragraph - 2-3 sentences)
   └─ Why this matters to the reader
   
2. Table of Contents (auto-generated from headings)
   └─ Help readers navigate
   
3. Introduction (150-200 words)
   └─ Context, problem, what they'll learn
   
4. Body (Main content - 1000-2500 words typically)
   └─ Use H2/H3 headers for structure
   └─ Break into scannable sections
   └─ Add images, diagrams, code blocks
   └─ Include examples and case studies
   └─ Link to relevant posts internally
   
5. Key Takeaways (Bulleted list)
   └─ 3-5 main points from the article
   
6. Call-to-Action Section
   └─ Next steps for reader
   └─ Related articles
   └─ Contact for collaboration
   
7. Author Bio (50-100 words)
   └─ About you and expertise
   └─ Links to social/projects
   
8. Related Articles (3-5 links)
   └─ Internal linking for SEO
   
9. Comments/Discussion (optional)
   └─ Community engagement

📊 SEO Elements:
✓ Primary keyword in title
✓ Primary keyword in first 100 words
✓ Related keywords throughout
✓ Internal links (at least 3-5)
✓ External authoritative links
✓ Image alt text with keywords
✓ Meta description with CTA
✓ Structured data (schema.org)
```

### 4.3 Technical SEO

```
ROBOTS.TXT:
Create file at root: /robots.txt
─────────────────────────────────
User-agent: *
Allow: /

Sitemap: https://yourdomain.com/sitemap.xml
Allow: /admin (only if protected)

SITEMAP.XML:
Auto-generate with Next.js
Include all pages, posts, projects
Update when new content added
Submit to Google Search Console

CANONICAL TAGS:
Add to each page: <link rel="canonical" href="https://yourdomain.com/page" />
Prevents duplicate content issues
Especially important for blog archives

STRUCTURED DATA:
Implement JSON-LD schema for:
- Article schema (blog posts)
- Person schema (about page)
- Project schema (portfolio items)
- Organization schema (footer)

Example Article Schema:
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Hydrogen Economy Explained",
  "description": "Complete guide...",
  "author": {
    "@type": "Person",
    "name": "Rohan Vashist"
  },
  "datePublished": "2025-01-15",
  "image": "image.jpg"
}

OPEN GRAPH TAGS:
<meta property="og:title" content="Article Title">
<meta property="og:description" content="Description">
<meta property="og:image" content="image.jpg">
<meta property="og:url" content="page-url">
<meta property="og:type" content="article">

Improves sharing on social media

TWITTER CARDS:
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Title">
<meta name="twitter:description" content="Description">
<meta name="twitter:image" content="image.jpg">

MOBILE OPTIMIZATION:
☐ Viewport meta tag present
☐ Responsive design
☐ Touch-friendly buttons (44x44px minimum)
☐ No blocking JavaScript/CSS
☐ Readable font sizes (16px+)

CRAWLABILITY:
☐ No blocking in robots.txt
☐ No noindex tags on important pages
☐ Clean URL structure
☐ No broken links (404s)
☐ Internal linking structure

SSL/HTTPS:
☐ All pages served over HTTPS
☐ Valid SSL certificate
☐ No mixed content warnings
☐ Redirect HTTP to HTTPS
```

## 7. ANALYTICS & TRACKING

### 7.1 Setup Google Search Console

```
1. Go to search.google.com/search-console
2. Add property: yourdomain.com
3. Verify ownership (via DNS or HTML file)
4. Submit sitemap.xml
5. Monitor:
   - Search queries (what people search to find you)
   - Impressions (how often you appear)
   - Click-through rate (CTR)
   - Average position (where you rank)
   - Coverage (pages indexed vs errors)
   - Mobile usability (no errors)

Key Metrics to Monitor:
├─ Top queries (keywords that work)
├─ Click-through rate (improve titles/descriptions if low)
├─ Position (aim for top 3 for main keywords)
├─ Crawl errors (fix broken pages)
└─ Mobile issues (ensure responsive)
```
